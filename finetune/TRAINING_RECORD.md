## Evaluation: 109 differently-worded student prompts (evaluate_answers.py)
Exact-match shortcut switched OFF, so every concept answer comes from the model:

| | Base qwen2.5:3b-instruct | Fine-tuned ostutor |
|---|---|---|
| Prompts passed (of 109) | 108 | 107 |
| Model answers replaced by the safety guard (of 93) | 8 | 0 |
| Total time | 551 s | 330 s |

Normal mode (stored answers allowed), final run with ostutor: 108 / 109, no timeouts.
Before the gap was fixed, both models said "SRTF is not optimal" (wrong); the notes now contain the
correct answer.

Honest reading: fine-tuning did not raise the keyword score. It made answers cleaner (no invented formulas or
numbers needing the guard), faster, and shorter. It also makes some yes/no answers very terse.
The test prompts are my own, so this is not an independent benchmark.
